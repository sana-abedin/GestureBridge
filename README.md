
# GestureBridge

### Real-Time Indian Sign Language Recognition System Using Computer Vision and Machine Learning

## 1. Introduction

GestureBridge is an AI-based application designed to recognize selected Indian Sign Language (ISL) hand gestures using computer vision and machine learning.

The system aims to make communication easier between sign language users and people who do not understand sign language.

## 2. Problem Statement

Communication between sign language users and non-sign language users can sometimes be challenging because of the language barrier.

GestureBridge aims to address this problem by recognizing selected hand gestures and converting them into readable text.

## 3. Objectives

- Detect hand gestures using a webcam.
- Extract hand landmarks using MediaPipe.
- Recognize selected ISL signs using machine learning.
- Display recognized signs as text.
- Provide optional speech output.

## 4. Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy
- Pandas
- Scikit-learn
- Streamlit

## 5. Project Scope

The initial version will focus on recognizing a selected vocabulary of Indian Sign Language gestures in real time.

The system will be developed as a software-based application.
